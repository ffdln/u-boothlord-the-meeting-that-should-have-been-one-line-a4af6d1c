The single sentence that could have replaced an entire pointless meeting — the decision was already made in the chat, so the meeting is just everyone reading the chat out loud to each other for an hour:

> We already agreed all of this in the chat, so this meeting is just us reading the chat out loud to each other for an hour.

`main.py` (Python 3.13, standard library only) writes that fixed sentence to
`/output/entry.txt`. Deterministic, no network.
